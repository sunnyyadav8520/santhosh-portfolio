# Yadava Santhosh Portfolio

A responsive, canvas-led portfolio for **Yadava Santhosh**, presenting a Biotechnology foundation alongside interests in Data Analytics, Quality Control, Research & Development, and laboratory opportunities.

## Local development

Install dependencies with `pnpm install`, then start the project with `pnpm dev`.

## Vercel deployment

This project includes `vercel.json` with the required Vite build settings. In Vercel, import the GitHub repository, keep the detected root directory unchanged, and deploy. The build command is `pnpm build`, and the generated site is served from `dist/public`.

## Assets

The GitHub export includes the profile image, logo mark, and résumé in `client/public/` so the external Vercel deployment remains self-contained.
